# 키움증권 REST API 연결하기

근거와 세부 내용은 [research/03-kiwoom-rest-api.md](research/03-kiwoom-rest-api.md)에 있다(조사일 2026-11-15). 이 문서는 순서만 추린 것이다.

**지금 이 프로그램이 키움으로 하는 일은 "연결 확인"까지다.** 토큰을 발급받고 잔고를 한 번 읽는다. 주문을 내는 실행기는 아직 없어서, 화면에서 모의투자·실전으로 전환할 수 없다. 연결 확인 코드도 문서 예시로 만든 테스트만 통과했고 실제 키움 서버에는 붙여 본 적이 없다.

## 1. 키 받기(본인이 직접, Windows나 macOS PC에서)

1. 키움증권 계좌와 HTS ID가 있어야 한다.
2. 먼저 **모의투자**를 신청한다: 키움 홈페이지 → 모의투자 → 상시모의투자.
3. [키움 REST API 포털](https://openapi.kiwoom.com)에서 "API 사용신청"을 한다.
4. "모의투자 App Key 관리"에서 모의투자용 App Key와 Secret을 내려받는다. **각각 한 번만 내려받을 수 있다.** 잃어버리면 해지하고 다시 발급받아야 한다.
5. 실전 키는 "계좌 App Key 관리"에서 따로 받는다. 모의투자로 충분히 확인한 뒤에 받는다.

## 2. 서버 IP 등록

- 포털에 **이 서버의 고정 공인 IP**를 등록한다(최대 10개). 등록하지 않은 IP에서는 오류 8050이 난다.
- 토큰은 발급받은 IP에 묶인다. 다른 IP에서 쓰면 오류 8010이다. 서버의 나가는 IP가 하나로 고정돼 있어야 한다.
- 집 PC에서 시험하려면 그 PC의 공인 IP도 등록해야 하는데, 유동 IP면 바뀔 때마다 다시 등록해야 한다.

## 3. 키를 서버에 넣기

서버의 `.env`에 넣고 다시 시작한다. 화면에서는 키를 입력받지 않는다.

```
KIWOOM_MOCK_APP_KEY=...
KIWOOM_MOCK_SECRET_KEY=...
```

## 4. 연결 확인

설정 → 거래 환경 → 모의투자 → **연결 확인**. 성공하면 예수금, 평가 금액, 보유 종목 수가 나온다. 실패하면 키움 오류 코드와 설명이 나온다.

| 자주 나올 오류 | 뜻 |
|---|---|
| 8050 | IP를 등록하지 않았다 |
| 8010 | 토큰을 발급받은 IP와 지금 IP가 다르다 |
| 8030, 8031 | 모의투자 키를 실전 주소에(또는 그 반대로) 썼다 |
| 8005, 8103 | 토큰이 만료됐거나 올바르지 않다 |

## 5. 주문 실행기를 만들기 전에 모의투자 서버에서 확인할 것

문서만으로 확정하지 못한 항목이 17개 있다(연구 자료 §19). 주문과 직접 관련된 것은 다음이다.

- 유량 초과 응답의 실제 모양과 체감 한도(모의투자는 TR당 초당 1회).
- 정정·취소 주문에서 거래소 구분을 원주문과 같게 보내야 하는지, 주문번호 자릿수.
- 실시간 주문체결(00)의 상태가 바뀌는 순서(접수 → 확인 → 체결).
- 토큰을 다시 발급받을 때 기존 토큰과 WebSocket 연결이 어떻게 되는지.
- 일봉 조회에 정규장 밖 체결이 섞이는지.

이 항목들을 모의투자에서 직접 확인한 뒤에 주문 실행기를 만들고, 그 뒤에 화면의 환경 전환을 연다.

## 알아 둘 제약

- 모의투자는 KRX만 지원한다. 그래서 1차 범위는 실전도 KRX만이다.
- 실전 주소를 3개월 동안 쓰지 않으면 서비스가 자동 해지된다. 모의투자 주소만 쓰는 것은 사용으로 치지 않는다.
- 키움 시세는 본인 투자 목적에만 쓸 수 있다. 이 프로그램은 한 사람만 쓰는 것을 전제로 한다.
- 2026-09-14부터 "최선집행기준 설명서"를 받지 않은 계좌는 주문이 거부된다. HTS·MTS에 접속하면 뜨는 안내에서 받는다.
- 매일 07:50~07:55쯤 키움 서버 점검으로 연결이 끊긴다.
