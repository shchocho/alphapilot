## 2. 주식 골라보기 (`/screener`)

- 왼쪽: "내가 만든"(직접 만들기) / "토스증권이 만든" 프리셋 목록 — 연속 상승세, 저평가 성장주, 꾸준한 배당주, 돈 잘 버는 회사 찾기 등 **쉬운 말로 된 전략 이름**, 인기 배지.
- 본문: 프리셋 제목 + 한 줄 설명("일주일 연속 상승세를 보이는 주식"), 필터 칩(국가·시장·산업·시가총액) + **적용된 조건이 파란 칩으로 노출**("주가 연속상승 - 5일 이상 연속"), "필터 추가".
- 결과 표: "검색된 주식 · 97개", 순위·관심·종목(로고+이름)·현재가·등락폭·등락률·태그(업종)·시가총액. 숫자 오른쪽 정렬.
- 시사점: 기법(미너비니·CANSLIM·터틀·변동성 돌파 …)을 **프리셋 스크린**으로 보여주고, 각 기법의 규칙을 칩으로 드러내 사용자가 조건을 이해·수정하게 한다.

## 3. 홈 (`/`)

- 상단: "국내 장 운영 / 해외 장 운영" 상태 칩, 지수 카드(미니 차트 포함), 주요 일정.
- 본문: 실시간 차트 순위 표(전체·국내·해외, 거래대금·거래량·급상승·급하락 탭) + **선택한 행의 미리보기 패널**(페이지 이동 없이 차트 확인).
- 시사점: 장 운영 상태를 가장 먼저 보여준다(자동매매에선 더 중요). 목록-상세 미리보기 패턴으로 이동 비용을 줄인다.

## 4. 색·표기 관례

- 상승 빨강, 하락 파랑. 구매 버튼 빨강, 판매 버튼 파랑.
- 가격은 천 단위 쉼표 + "원", 등락률은 부호와 함께 괄호 표기.
- 정보 밀도는 높지만 카드 간 여백과 얇은 구분선으로 정리. 장식 요소가 거의 없다.
